# 🎯 Adobe Stock Checker - LM Studio Version

100% Offline, 100% Free Image Analysis Tool

## ✨ Features

- ✅ Image Analysis (Accept/Reject probability)
- ✅ LM Studio Integration (Local AI)
- ✅ 4 Rejection Reasons Detection
- ✅ Quality & Uniqueness Scoring
- ✅ 100% Offline - No Internet Required
- ✅ 100% Free - No API Cost
- ✅ Bengali Support

## 🚀 Quick Start

### Requirements
- LM Studio (Free): https://lmstudio.ai
- Node.js
- 4GB+ RAM

### Installation

1. Download LM Studio
2. Load an AI model (llama-2, mistral, etc)
3. Start Local Server
4. Clone this repo
5. Run: `node server.js`
6. Open: `http://localhost:3000`
